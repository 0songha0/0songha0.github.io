## AWS 리소스 종료 방법

사용하지 않는 AWS 리소스가 있으면 계속 비용이 부과되므로 삭제해두는 것이 좋습니다.

### EC2 서버 종료 방법
AWS > EC2 검색 > 인스턴스 메뉴 > 인스턴스 목록에서 삭제할 EC2 서버 선택 > 상단 인스턴스 상태 버튼 > 인스턴스 종료(삭제) > 종료(삭제)  
사용하지 않는 EC2 서버는 비용이 많이 나갈 수 있으니 종료시켜주는 것이 좋습니다.

EC2 서버를 종료하면 삭제 시 종료하도록 설정된 EBS 볼륨은 함께 삭제됩니다.  
추가로 연결된 EBS 볼륨이 남아있는지 확인하고, 사용하지 않는 볼륨은 별도로 삭제하는 것이 좋습니다.

### EC2 AMI 이미지 삭제 방법
AWS > EC2 검색 > 이미지 > AMI 메뉴 > 작업 > AMI 등록 취소 > AMI 등록 취소

### EC2 스냅샷 삭제 방법
AWS > EC2 검색 > Elastic Block Store > 스냅샷 메뉴 > 스냅샷 목록에서 삭제할 스냅샷 선택 > 작업 > 스냅샷 삭제 > 삭제 입력 > 삭제

### 로드밸런서 삭제 방법
AWS > EC2 검색 > 로드 밸런싱 > 로드밸런서 > 로드밸런서 목록에서 삭제할 로드밸런서 선택 > 작업 > 확인 입력 > 삭제

### RDS 삭제 방법
AWS > RDS 검색 > 데이터베이스 메뉴 > 데이터베이스 목록에서 삭제할 RDS 선택 > 작업 > 삭제 > 최종 스냅샷 생성, 자동 백업 보존 체크 해제 (비용 부과 방지) > 인스턴스 삭제 시 시스템 스냅샷 및 특정 시점으로 복구를 포함한 자동화된 백업을 더 이상 사용할 수 없다는 점을 인정합니다. 체크 > delete me 입력 > 삭제

### CloudWatch 대시보드 삭제
AWS > CloudWatch 검색 > 대시보드 메뉴 > 사용자 지정 대시보드 목록에서 삭제할 대시보드 선택 > 삭제 > 삭제

### CloudWatch 경보 삭제 방법
AWS > CloudWatch 검색 > 경보 메뉴 > 모든 경보 > 경보 목록에서 삭제할 경보 선택 > 작업 > 삭제 > 삭제

## AWS 비용 확인 방법
우측 상단 로그인 계정명 > 결제 및 비용 관리 > 청구 및 결제 > 청구서 메뉴 > AWS 예상 청구서 요약 및 서비스별 요금 확인 가능  
사용하지 않는 AWS 리소스로 비용이 부과되고 있는지 확인하고 종료하거나 삭제하면 됩니다.
