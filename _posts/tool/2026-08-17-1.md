## DataGrip
관계형 데이터베이스 및 NoSQL 데이터베이스를 관리할 수 있는 DB 전용 IDE입니다. 
JetBrains에서 개발했으며 SQL 자동완성, 코드 분석, 객체 탐색 기능 등을 제공합니다.

회사 업무 등 상업적 용도로 사용하려면 유료 라이선스가 필요합니다.

### DB 연결 방법
좌측 Database Explorer > New > Data Source > DB 유형 선택 > Name : DB 이름 입력 > Host : DB 서버 IP 또는 호스트명 입력 > User : DB 유저명 입력 > Password : DB 유저 비밀번호 입력 > 하단 Test Connection > Succeeded 메시지 확인 > OK

### 모든 스키마 보기 설정 방법
좌측 Database Explorer > 연결된 DB 좌측 화살표 클릭 > No schemas selected ... 클릭 > All schemas 체크 > 다른 영역 클릭 시 적용 완료

### DB 쿼리 콘솔 열기
좌측 Database Explorer > 데이터베이스 우클릭 > New > Query Console 선택  
SQL 쿼리를 작성하고 실행할 수 있는 쿼리 콘솔을 엽니다.

<mark>DB 스키마 선택 방법</mark>  
```
use DB명;
```
쿼리 콘솔에서 위 쿼리를 실행하거나, 우측 `<schema>` 클릭 후 DB 스키마를 선택하면 됩니다.
